# CS116 Credit Risk Prediction System

A data science project focused on data exploration, preprocessing, feature engineering, and machine learning model development.

## 📌 Project Overview

This project applies data science and machine learning techniques to analyze a dataset and build predictive models. The workflow covers data collection, exploratory data analysis, data preprocessing, feature engineering, model training, and evaluation.

## 🚀 Project Workflow

- **Data Collection:** Gathered and organized the dataset for analysis.
- **Exploratory Data Analysis (EDA):** Analyzed data distributions, patterns, and relationships between features.
- **Data Preprocessing:** Cleaned missing values, handled categorical and numerical features, and prepared data for modeling.
- **Feature Engineering:** Selected and transformed relevant features to improve model performance.
- **Model Development:** Trained and evaluated machine learning models.
